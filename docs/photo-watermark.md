# 写真のロゴ表示

運営は **株式会社IMAKAI**。LP・プライバシー案内・素材クレジット・撮影証明ページと、アプリの設定／「JustTakenについて」に掲載する。

写真には白いJustTakenロゴとライム色のポイントを右下に重ねる。初期値はオン。マイページ → 設定 →「写真にロゴを表示」からオン／オフを変更し、その場でプレビューできる。

## 原本と撮影証明

ロゴはReact NativeのView/SVG表示レイヤーであり、撮影ファイルには書き込まない。撮影セッション、manifest、ハッシュ、署名、アップロード、R2原本に変更はない。HEIF・RAW・HDRを含む原本のバイト列と証明を保つ。署名付き証明と原本の書き出しも従来どおりで、ロゴを焼き込まない。

ブランドロゴは撮影認証の有無を表さない。サンプル画像にも表示されるため、撮影記録の状態表示と区別する。動画のポスターは写真用ロゴの対象外。

## 設定の範囲

- この端末で閲覧する写真の表示設定。サンプル、検索・保存写真、下書き、実投稿のプレビュー／原画表示に適用する。
- `justtaken.photo-watermark.v1` をAsyncStorageに保存。未設定はオン、保存値 `off` の場合のみオフ。設定を読み込むまでマークを出さず、オフからオンへの一瞬のちらつきを防ぐ。
- 書き込み中はスイッチを無効にし、保存に成功してから表示を更新する。失敗時は前の状態を維持しエラーを表示する。
- アカウント間／端末間で同期しない。投稿者の設定を他の閲覧者へ配る投稿属性や、外部SNS用のロゴ入り画像ファイルの生成は未実装。外部共有する原本はロゴなし。

## LPの体験

https://justtaken.app/#watermark に同じ見た目の切り替えを設ける。体験用の写真とアプリ画面モックのロゴが連動する。写真が素材であることを明示する。LPの設定はブラウザの `justtaken.lp.watermark.v1` に保存し、アプリ設定とは分ける。保存できないブラウザでもそのページ内で切り替えられ、保存不可を案内する。プライバシー案内にも用途を記載する。
