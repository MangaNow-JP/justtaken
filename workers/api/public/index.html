FAQ

よくある質問

ほかにご不明な点は、運営会社のお問い合わせフォーム ↗からご連絡ください。

いつから使えますか？

現在、iOS・Android向けに開発中です。公開日が決まり次第、先行登録いただいた方へご案内する予定です。先行登録は無料で、アプリのアカウント作成とは別の受付です。

AIや加工は使わないのですか？

JustTakenは、アプリのカメラで実際に撮影した写真と動画を大切にします。AIで被写体を生成したり、顔や景色を書き換える編集機能は設けません。端末のカメラによる露出・HDRなどの通常の撮影処理は使用します。

AI生成ではないことを証明できますか？

アプリ内の撮影経路と、受け取ったファイルが保存原本と一致するかを確認できます。AI画像を映した画面の撮り直しなどは識別できないため、「AIが一切関わっていない」という完全な証明ではありません。第三者の時刻認証と監査ログで撮影記録を補強します。

原本の画質や、動画の長さは？

保存する原本は再エンコードせず、写真・動画の画質を保持します。動画は最大60秒、音声付きでの撮影に対応します。形式・解像度・HDRなどの対応範囲は端末やカメラによって異なります。

写真を公開せずに使えますか？

はい。撮影した原本と証明を、自分用に保存できます。SNSへの投稿は任意です。証明だけを必要な人に共有し、あとから共有リンクを停止することもできます。

先行登録の情報はどう扱われますか？

メールアドレスと利用予定の端末を、公開のご案内と登録の管理に使います。広告配信や販売には利用しません。保存期間は登録から180日で、登録完了時に保存できる控えのリンクから取り消せます。詳しくはプライバシーポリシーをご覧ください。
