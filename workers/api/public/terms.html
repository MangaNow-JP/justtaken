現在の提供状況

先行登録と撮影証明の検証ページを公開しています。写真・動画SNSアプリは開発中です。

01適用範囲と提供状況

この利用規約（以下「本規約」）は、株式会社IMAKAI（以下「当社」）が提供するJustTakenのウェブサイト、先行登録、撮影証明の検証機能、および提供を開始したアプリの利用条件を定めます。

現在公開しているのは、サービス紹介、先行登録および撮影証明の検証ページです。iOS・Androidアプリは開発中です。本規約に記載するアプリの撮影・保存・投稿・共有機能に関する条項は、その機能が提供され、利用する場合に適用されます。記載によって公開日や全機能の提供を約束するものではありません。

個人情報の取り扱いは、プライバシーポリシーで定めます。個別の利用条件を設ける場合は、対象となる機能の利用前に提示します。

02先行登録

先行登録は、公開案内を受け取るための無料の受付です。アプリのアカウント作成、利用予約、購入、優先利用権の取得とは異なります。ご自身が利用できるメールアドレスを登録してください。

登録情報の保存期間は登録日から180日です。完了画面から保存できる控えのリンクで登録を取り消せます。同じメールアドレスの再登録では、最初の保存期限や取り消しリンクは更新されません。現在、登録確認メールは送信していません。

公開日、案内の時期、アプリの価格は未定です。有料機能を提供する場合は、料金と条件を事前に提示し、別途申し込みを受け付けます。先行登録だけで料金が発生することはありません。

03アカウントと利用環境

JustTakenアプリのアカウント登録・利用は18歳以上の方を対象とします。18歳未満の方は、保護者の同意がある場合も登録・利用できません。登録時および利用規約への同意時に、18歳以上であることをご自身で確認して申告してください。お住まいの地域の法令により、さらに厳しい利用条件が適用される場合は、その条件も満たす必要があります。

年齢の確認は自己申告に基づき、生年月日や身分証を収集する年齢認証ではありません。Google・Appleへのログインや端末認証の成功も、成人であることの証明にはなりません。18歳未満の利用が判明した場合は、利用停止やアカウント削除等、状況と法令に応じた対応を行います。

アカウントを使用する機能では、ご自身が利用権限を持つ認証手段を使用し、ログイン情報や共有リンクの秘密情報を適切に管理してください。他人へのなりすまし、アカウントの不正利用はできません。

撮影・音声収録・位置情報の取得には、対応する端末とOSの許可が必要です。形式、画質、HDR・RAW等の対応範囲は、端末、カメラ、OSによって異なります。通信費や端末の利用に必要な費用は利用者の負担となります。

04撮影と原本の取り扱い

JustTakenは、アプリのカメラで撮影した写真・動画を記録するサービスです。動画は最大60秒です。写真・動画の原本は、対応する保存形式を保ち、再圧縮せずに保存する設計です。表示用のプレビューは原本とは別に作成する場合があります。

ロゴの表示は設定で切り替えられます。ロゴの表示だけで、ファイルや撮影証明の検証が済んだことを示すものではありません。ロゴの表示設定は、原本と撮影証明の内容を書き換えません。

共有先のサービスによる圧縮・変換やメタデータの変更によって、原本との照合が一致しなくなることがあります。原本と証明は、必要に応じてご自身でも保管してください。

05撮影証明で確認できる範囲

撮影証明は、当社が記録したアプリ内での撮影経路、署名、および照合するファイルが記録された原本と一致するかを確認するためのものです。

  • 被写体や出来事の真実性、撮影者の実名・本人性、著作権の帰属、AIが一切関与していないことを認定するものではありません。
  • AI画像を映した画面や印刷物の再撮影、演出された場面、端末やOSの侵害などを完全に排除するものではありません。
  • 端末の撮影日時・位置は、端末が報告した値です。第三者時刻認証は、その時刻までに証明が存在したことを示し、実際の撮影日時や場所を保証しません。
  • 第三者の時刻認証・監査ログは、変更を検出する手がかりです。「改ざん不可能」を保証するものではありません。通信障害や未完了の状態では、確認できる範囲が限定されます。
  • 検証結果のスクリーンショットやロゴは、署名付き証明ファイルの代わりにはなりません。

保険、点検、取引等で利用する場合は、他の資料とあわせて確認してください。JustTakenは、事故の実在、不正の有無、保険金の支払可否、法的な証拠能力を自動的に判断・保証するサービスではありません。

06公開・共有と削除

アプリのアカウントは非公開を初期設定とし、利用者が指定した公開範囲に従ってコンテンツを取り扱います。SNSに投稿せず、原本と撮影証明を保存することもできます。

証明の共有リンクには、原本の写真・動画は含まれません。リンクを知る人は、証明を閲覧し、保存・転送できる場合があります。リンクの停止や期限切れで、相手がすでに保存したファイルまで削除することはできません。

SNS投稿の削除と、保存済みの原本・撮影証明の削除は異なります。原本を削除するときは、原本・証明を対象とする削除操作を行ってください。第三者の公開監査ログに登録済みのハッシュ等や、相手が保存済みの証明は残ります。詳しくは保存期間と削除をご確認ください。

07コンテンツの権利

撮影・投稿した写真、動画、文章等の権利は、利用者または正当な権利者に帰属します。利用者は、第三者の著作権、肖像権、プライバシー等を侵害しないよう、撮影・投稿・共有に必要な権利や同意を確保してください。

当社は、利用者が選択した機能の提供に必要な範囲で、コンテンツを保存・複製し、表示用プレビューを作成し、配信・検証することができます。公開範囲を超えて宣伝に使用したり、生成AIの学習に使用したりするための許諾を、本規約により取得するものではありません。

本サイトのロゴ、文章、デザイン、ソフトウェア等の権利は当社または正当な権利者に帰属します。法令で認められる利用や、権利者の許諾による利用を妨げるものではありません。

08禁止事項

次の行為は禁止します。

  • 法令違反、詐欺、なりすまし、第三者への脅迫・嫌がらせ、権利侵害
  • ヌード・性的コンテンツの投稿・共有
  • 報道目的を逸脱した露骨な暴力表現の投稿・共有
  • 児童の性的虐待・搾取、その他の違法な性的搾取コンテンツ、本人の同意のない性的な画像、差別や暴力を不当に助長する内容の投稿・共有
  • 他人の写真や生成画像の再撮影等を、撮影証明の範囲を偽って本人の実写や事実の証明として使用する行為
  • 撮影証明、検証結果、ロゴ等の偽造、改変、誤認を生む表示
  • 認証や公開範囲の制限の回避、不正アクセス、秘密情報の取得、サービスの妨害
  • 本人の同意なく他人の個人情報を収集・公開する行為

報道目的という表示だけで露骨な暴力表現を許容するものではありません。報道目的であっても、ヌード・性的コンテンツ、児童の性的虐待・搾取、その他の禁止事項は例外として認められません。

公開された証明・公開鍵を、受け取ったファイルの照合や正当なセキュリティ検証に利用することを、一律に禁止するものではありません。

09違反への対応と申し出

権利侵害、不正利用、セキュリティ上の問題がある場合、当社は内容に応じて、表示・共有の停止、コンテンツの削除、利用の一時停止等、必要かつ相当な措置を講じることがあります。緊急の場合や法令上通知できない場合を除き、理由と対応について説明するよう努めます。

権利侵害の申告や措置への異議がある場合は、対象のURL・証明ID等と事情を、下記の問い合わせ先へお知らせください。パスワード、ログイン用コード、共有リンクの秘密部分を送る必要はありません。

10サービスの変更・中断・終了

保守、不具合、通信・外部サービスの障害、不正利用への対応等により、機能を変更・中断する場合があります。重要な変更や終了については、緊急またはやむを得ない事情がある場合を除き、サイト等で事前に案内し、必要なデータの保存機会を確保するよう努めます。

端末故障、利用環境、外部サービスの状況等により、機能が利用できない場合があります。提供される機能の範囲、端末の対応状況、検証結果に表示される状態を確認してください。

撮影証明が確認する範囲は第5項のとおりです。その範囲を超える事項を保証しないことと、当社が法令上負う責任を免除することは異なります。利用者の法令上の権利を制限する条項が無効となる場合でも、その他の条項は可能な範囲で有効に存続します。
